# S48：自訂一人稱重入修正

## 授權與目標
- 使用者在 S47 建議「查明意圖後修正兩項」後授權選下一步繼續，本階段處理該建議。
- 修正自訂稱呼重新開啟後直接確認遺失讀音編碼、以及選 [50] 性格預設越界。
- 以原作自訂編碼／解碼、首次設定及性格預設分支推導意圖，不自行更改其他設定規則。

## 範圍
- 查 `FIRSTSETTING_CHARA.ERB@FIRSTSETTING_CHARA_SELFCALL` 的初始化、[50]、[99]，及 `SELF_CALL.ERB` 編碼讀取。
- 自訂設定重入後不改直接確認，CFLAG:8 與 CSTR:4 必須保留完整原值。
- 重入後選性格預設，依首次自訂設定切回預設的原作路徑選擇稱呼與合法字形。
- 取消保持原值；改成其他標準／自訂稱呼時使用使用者新選擇。
- 特別檢查平假名、片假名、四音、拗音、重複重入及存讀檔後重入。
- 不修正其餘已記錄的原作怪處，也不改既有孩子加入預設路徑。
- 程式標 DEVIATION，登記偏離原作的兩項修正、依據與此次授權脈絡。
- 若發現意圖不足以唯一確定的行為，先整理具體選項再詢問，勿自行擴大修正。

## 驗收
- 從原作既有成功路徑推導預期，先紅後綠；移除已修正的舊錯誤預期。
- 實際 Web 設定→返回→重入→確認／預設，以及存讀檔驗證。
- 主代理完整 pytest 全綠，source／reference 無修改，LF／UTF-8 無 BOM。
- 預設與 tokusou 各 seed 0–249、max-shop 200、actions 101–108，每批 50 局前景執行。
- 與 S47 逐 seed 比較完整記錄、停止原因及 catalog 失敗。
- 更新 STATUS（≤120 行）、一人稱 wiki、deviations；無新未決事項則不更動 unresolved。
- 主代理驗收、commit 並 push main；完成本階段後停止。
