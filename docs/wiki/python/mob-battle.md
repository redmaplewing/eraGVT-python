# 雜魚戰（S33）

## 實作邊界

`game/battle/mob.py` 手翻遭遇、16 種敵資料、普通／特殊行動選擇、反應與指令選項；
`mob_special.py` 手翻共用指令公式與 102／803／901 的 7 個專用指令。
`encount`、`core`、`enemy`、`sexcom`、`restraint`、`source_check`、`after` 接回既有戰鬥流程。
只有 `MESSAGE_*` 顯示函式使用 catalog；敵資料與指令規則沒有交給 ERB 執行器。
原文的顯示函式包含狀態寫入時，沿 S29 的 GameState 寫入／Python hook 機制處理。
無 catalog 時明確停止；未移植的市民戰、命名、裏プロフィール、除錯輸入仍保持停止。

## 流程依據

以下路徑相對 `source/earGVP/ERB/ゲーム内_戦闘処理/`。

- `ENCOUNT.ERB@MOB_TENTACLE_ENCOUNT:429–447`：啟用 802 bit4 時進入戰鬥；否則保持既有簡易遭遇。
- `ENCOUNT.ERB@MOB_TENTACLE_BATTLE:528–602`：依 MOB_FLAG 權重選敵、無候選回傳 -1、指定敵資料及旗標初始化。
- `COMMON_TENTACLE_DATA.ERB@TENTACLE_ACCESS:198–309`：敵資料派送；`GAPING.ERB@SET_TENTACLE_SIZE:1137–1169`：
  原作沒有 MOB 專用尺寸函式，CATCH 採 120／80／80／120 與各 1 的比率。
- `戦闘コマンド(性攻撃)/SEX_COMABLE.ERB@SEX_COMABLE:17–23、588–593`：附加選項與 2000 號段專用指令。
- `戦闘コマンド(ヒロイン)/COMABLE.ERB@COM_ABLE101:893–905`、`@COM_ABLE103:991–1020`：依敵人的分類／反應決定可選指令。
- `戦闘コマンド(ヒロイン)/COMF100.ERB@COM100:52–62`、`COMF102.ERB@COM102:13–22`、
  `COMF103.ERB@COM103:192–200`、`BATTLE_COM_AFTER.ERB@SOURCE_CHECK:1151–1161`：反應派送。
- `BATTLE_COM_AFTER.ERB@SOURCE_CHECK:417–435`：勝利探索度；`BATTLE_TRAIN_AFTER.ERB@EVENTEND:228–260、507–524`：
  經驗、訓練、金錢、防衛力、變身／衣裝與暫存狀態清理。
- `TENTACLE_SYASEI.ERB@TENTACLE_SYASEI_CHECK:90–119`：901 的特殊結算。

## 照原作保留的細節

- `TENTACLE_MOB_102_スライム（ぷるぷるスライム・アス）.ERB@TENTACLE_MOB_102_ATTACK_ROUTINE:133–138`
  與 702 同名後綴函式沒有為 LOCAL 抽亂數，保留初始／殘值，不能補 RAND。
- `TENTACLE_MOB_803_物質（メカ触手）.ERB@SEXCOM_OPTION_MOB_803_COM3:507–508、637–638` 重複定義，取先定義。
  引擎：`reference/emuera-1824/Emuera/GameProc/LabelDictionary.cs:58–77`、`LogicalLine.cs:274–282`。
- `../クズ市民/CITIZEN_1.ERB@MESSAGE_MOB_901_COM2:408–656` 與 901 檔同名。原作 `emuera.config:40` 啟用檔名排序，
  引擎 `reference/emuera-1824/Emuera/Config/Config.cs:330–379` 子目錄先、OrdinalIgnoreCase 排序，
  所以取 CITIZEN_1；僅將這個已被雜魚呼叫的顯示函式加入 catalog 可寫範圍，未開放市民戰規則。
  同檔 `@SEX_TYPE_MOB_901_COM2:405–406`、`@SEXCOM_OPTION_MOB_901_COM2:658–666` 與 901 檔數值相同。
- `TENTACLE_MOB_SPCOM.ERB@MOB_CREATE_COM:130–136` 的分母為Ｃ感覺；`:203–204` 使用 ARG:11 與Ｖ結界分母。
  原樣保留，測試以不同部位數值區分，沒有按名稱修正公式。
- `TENTACLE_MOB_803_物質（メカ触手）.ERB@SEXCOM_MOB_803_COM2000:1214` 的 LOCAL:3 是累加 10。
- `ERB/ヒロイン関連/CHARA_STATE_CHANGE.ERB@STATE_CHANGE_EXTRAEFFECT:342–359` 要兩個數值，但
  `ENEMY_ACTION.ERB@ENEMY_ACTION:251、370、547、735、914` 只傳 TCVARn:15。保留該參數順序與省略值 0，
  不改成 TCVARn:14／15；省略值依據 `reference/emuera-1824/Emuera/GameProc/ErbLoader.cs:581–590`。
