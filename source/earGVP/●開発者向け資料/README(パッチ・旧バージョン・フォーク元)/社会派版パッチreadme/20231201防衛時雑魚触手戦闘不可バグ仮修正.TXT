eraGVT_社会派触手ニュース版231130用防衛時雑魚触手戦闘不可バグ仮修正

防衛時に悪堕ちキャラや雑魚触手との戦闘が発生するようにしてみた
おまけで、フリープレイ時ボス触手を倒したさいに[―――]が無限に増殖していくのを修正

やったこと
雑魚触手戦闘開始判定位置を\ERB\SHOP_ACTION.ERBから\ERB\ゲーム内_行動実行処理\ACTION_GUARD.ERBに

\ERB\SHOP_ACTION.ERBの雑魚戦闘判定（176行目）で、雑魚触手の場合はRESULTが1以上になっていて、このままだと戦闘が発生しないのでRESULTが0とそれ以外の場合に変更してみる

現状の疑問点
ボス触手が出てくる
出てくるのが本則で、こっちのプレイパターンが特殊だっただけな可能性が高い気がするので一応そのまま
なので、”仮”修正


おまけは\ERB\SHOP.ERBの990行目にSIF一個追加しただけ

あと、ACTION_GUARD.ERBのインデントが半角スペースになってたけど、他のERBではTABになっていて仕様が混在すると、後々問題が起きる可能性がないとは言い切れないのでTABに変更
とりあえず関数の直後はインデント下げる必要はないかと
