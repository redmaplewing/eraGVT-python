eraGVT_社会派触手ニュース版(2834.zip版)用のパッチです

巫女服やチャイナドレスをカスタマイズしようとしたりするとエラーが出るのをとりあえず修正
	HP、DEF、NOINNER、SLOTがあると起こるっぽいのでとりあえずCLOTH_衣装カスタマイズ共通処理.ERBの46行目からのSELECTCASE文で対処
>>410で衣装引き継ぐ場合に装備なしならCFLAG40～42を-1にしておく処理を入れ忘れたので追加
衣装設定でテンタクルスーツを装備中、アウター（変身後）を設定しないを選んでも通常のアウター側がテンタクルスーツ装備のままになっていたのを修正
キャラメイク時、CSVでアウターにテンタクルスーツを設定してた場合、もう片方のアウターにもテンタクルスーツを設定するように

それとオマケでCFLAG:45～47をCFLAG:40～42に統合したパッチを付属
	CFLAG:40～42とCFLAG:45～47で分けている意味がなさそうだったのと、キャラメイク時にテンタクルスーツを装備したりするとおかしくなったり、
	衣装設定で装備なしを指定できるようにしてみたかったので作ってみました
	不具合や分けている意味があった場合に備えて別に分けています。使う場合はこのファイルと同じフォルダにあるERBフォルダを先に使ってからにしてください
