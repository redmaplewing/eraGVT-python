eraGVT社会派220121用男の娘と巨尻爆尻追加パッチ

★概要
ふたなりの管理を真似して男の娘素質を追加しました。
ふたなりと同じく、変身前後で別々に所持できます。

男の娘素質をつけるとスリーサイズや外見が設定できるようになります。
ただしお胸のサイズは絶壁相当に固定です。
また、身長の計算の仕方も女の子と同じになります。

現時点で男の娘素質はフレーバーです。
イベント対応は僕らができなければ次の世代がやってくれますってニュータイプが言ってました。

巨尻と爆尻についてはかなり雑な追加です。
大きさはとりあえずのものですし、体重についてもお尻の大きさは影響しません。
その辺りの計算があまりにも職人技過ぎるのでこれ以上手を出さないのが正解と判断しました。
細かい調整は詳しい方にお任せします。

本パッチはeraはおろかプログラミング素人が作成したものです。
品質には注意していますがどこかおかしいところがないとも言い切れません。
というか多分あるので自己責任でバックアップはしておいてください。
