※eraGVT_社会派触手ニュース版(240105) 오리지널 버전용 [반격] 전투 스타일 패치 (by pororoking)※

반갑습니다, eraGVT0.394 버전 때부터 지금(사회파뉴스판240105)까지 한국어 번역판 및 한국어판 오리지널의 [반격] 전투 스타일을 제작한 pororoking 입니다.

모티브는 몬스터 헌터 시리즈의 태도를 보고 영감을 받았습니다.
납도 자세에서 상대가 공격해 오는 순간에 크로스 카운터가 들어가는 게 멋있잖아요.
마침 eraGVT의 전투가 꽤 재밌었던 한편 아쉽다고 느껴지기도 해서, 이참에 GVT에서 직접 재현해 보자! 라는 생각으로 만들어 봤습니다.

막상 만들어 놓고 방치된지 거의 1년 뒤에 다시 손을 대게 됐습니다만...
전 개발을 할 줄 몰라서요, 거의 모두 다 하드코딩으로 떼우는 바람에 [반격] 스타일이 완전히 한국어판 독자 사양이 되고 말았습니다.
그래서 오리지널 버전에 맞춰 [반격] 스타일 패치 부분만 쏙 빼왔습니다.

만약 반응이 괜찮다면 한국어판 사양의 전투 밸런스 패치도 공유하고자 합니다만...

대부분 기존의 OP스러운 요소들을 변경하고, (지략 스타일은 명중률+ -> 치명타 배율+ 로 변경, 전투 스타일 중복 금지 옵션 추가 등등)
밸류가 낮은 FEAT들을 상향시키는 방향으로 패치가 되고 있습니다. (에어마스터 -> 치명타율+, 에어 스트라이크로 회피 시 공중 대시 회복이라든지)

전자는 호불호가 갈리더라도, 후자라면 색다른 빌드를 만들어 좀 더 촉수를 때려잡는 맛이 날 것 같은데, 여러분은 어떠실지 궁금합니다.

지금까지도 계속 eraGVT 개발에 힘써주시는 모두에게 감사와 존경의 말씀 전해 드립니다.

※eraGVT_社会派触手ニュース版(240105)オリジナル版用[反撃]戦闘スタイルパッチ(by pororoking)※

はじめまして、eraGVT0.394バージョンから今(社会ファニュス版240105)まで韓国語訳版および韓国語版オリジナルの[反撃]戦闘スタイルを製作したpororokingです。

モチーフはモンスターハンターシリーズの態度を見てインスピレーションを得ました。
納刀姿勢で相手が攻めてくる瞬間にクロスカウンターが入った方がかっこいいじゃないですか。
ちょうどeraGVTの戦闘がなかなか面白かった一方で、残念だと感じることもあるので、ついでにGVTで直接再現してみよう！ という思いで作ってみました。

いざ作っておいて、放置されてからほぼ1年後にまた手を出すようになったのですが…
私は開発ができないので、ほとんど全てハードコーディングで外してしまって「反撃」スタイルが完全に韓国語版独自仕様になってしまいました。
なのでオリジナルバージョンに合わせて [反撃]スタイルのパッチ部分だけを 抜いてきました。

もし反応が良ければ韓国語版仕様の戦闘バランスパッチも共有したいですが···

ほとんど既存のOPらしい要素を変更し、 (知略スタイルは命中率+->クリティカル倍率+に変更、戦闘スタイル重複禁止オプション追加など)
バリューの低いFEATを引き上げる方向でパッチになっています。 （エアマスター->致命打率+、エアストライクで回避時の空中ダッシュ回復とか）

前者は好き嫌いが分かれても、後者なら変わったビルドを作り、もう少し触手を打つ味がすると思いますが、皆さんはどうなのか気になります。

これまでもずっとERAGVTの開発に力を注いでくださる皆様に感謝と尊敬の言葉をお伝えします。
