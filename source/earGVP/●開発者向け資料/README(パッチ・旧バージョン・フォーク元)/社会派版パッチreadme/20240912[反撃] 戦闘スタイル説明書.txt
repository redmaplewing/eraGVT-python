1.戦闘スタイル[反撃]追加


1-1.

[反撃]スタイルは(攻撃0.70 *防御0.50)の攻撃力を持っており、敵の攻撃を防いだり(Guard)回避(Miss)することで攻撃する機会を得る方式で運営されます。


1-2.

反撃スタイルには（通常反撃、EX反撃）この2つの技があります。

まず通常反撃の場合は（近?中?遠）距離攻撃中に反撃スタイルが適用された距離の攻撃を試みると「反撃体勢」をとることになり、敵の攻撃を防御する準備をします。

次にEX反撃は、同様に反撃スタイルが適用された距離にあるときに防御コマンドを使用すると既存の防御効果の代わりに「EX反撃体勢」をとることになります。


1-3.

通常の反撃は敵の攻撃を防御する時に受けるダメージを小幅減少させ、+10％の直撃率ボーナスと共に反撃を開始します。

低い確率で完全防御に成功しすべてのダメージを無効にすることもできます。
(完全防御は以下1-4項目において詳述)

ただし(体液?波動?絡みつく?押し倒す)などの特殊な攻撃は、完全防御に成功したり回避したりしてこそ反撃に成功することができます。

また、完全防御が不可能な攻撃も存在します

また、エアストライクによって空中からの敵の攻撃を回避した場合でも反撃に成功します。

*敵の攻撃範囲外にいる場合は反撃不可能



1-4.

EX反撃の場合、敵の通常攻撃を確定的に防御することになり、+20％の直撃率ボーナスとともに「完全防御(PERFECT GUARD)」判定となり、敵から受けるダメージを無効化します。

「体液?波動」攻撃は低い確率で完全防御に成功させることができるが、「絡みつく?押し倒す」は防御できず、通常の反撃と同様に回避しなければ反撃できません。

またEX反撃による「完全防御」を成功させる場合は(気節?べとべと)状態以上の抵抗効果とともに、べとべと状態異常を確定的に回復させることができます。



1-5.

戦闘中に反撃で軽減または無効化させたダメージを蓄積させることができます。（限度値を超えても蓄積が可能）

蓄積させたダメージはバースト攻撃に使用することができます。（以下1-6項目に述べる）

限度値は、以下の式によって計算されたキャラの消耗度によって変化します。

反撃以外の戦闘スタイルにも同様に当てはまります。

(最大体力+最大気力)*100 / (体力+気力+{疲労度*150})
-> 100~75％：最大体力の120％		74~40％：最大体力の100％	    39％~：最大体力の80％


1-6.

バースト攻撃を使用する場合は一時的に実攻撃力が（攻70％+防50％）->（攻35％+防25％）に半減し、
蓄積させたダメージを最終被害量に加算してダメージを与えます。

つまりクリティカル倍率まで計算がすべて終わった後に蓄積ダメージを加算します。

その後、反撃体勢を取らずにそのままターンを終了します。

*バースト攻撃が有効になったままEX反撃を行う際、バーストの効果が適用されないままEX反撃を行います。


バースト攻撃を使用する時、蓄積させたダメージが限度値より1％超過するごとに最大体力の1％分のダメージを反動で受け(最大50％)、

同時に限度値より5％を超えるたびに疲労度が3分累積されます。

(例)    限度値が最大体力の100％であり、ダメージが限度値の120％分蓄積されたときにバースト攻撃を使用すると
        20％のダメージを反動で受け、3*4=12だけの疲労度が累積



2. 防御?完全防御に関する修正


2-1.

「HIT?MISS?GRAZE?CRITICAL HIT」の計4つの判定に、操作キャラ専用の「GUARD(防御)?PERFECT GUARD(完全防御)」判定が追加されます。



2-2.

防御及び通常反撃の体勢中、敵の通常の攻撃を被弾した時に「HIT(被撃)」判定の代わりに「GUARD(防御)」判定が表示されるように変更しました。



2-3.

防御体勢の中でも敵の通常攻撃を受ける時に低い確率で「PERFECT BLOCK(完全防御)」判定を成功させることができるようになり、
EX反撃と同様に（ダメージ無効）及び（状態異常抵抗）効果を得るように変更されます。
