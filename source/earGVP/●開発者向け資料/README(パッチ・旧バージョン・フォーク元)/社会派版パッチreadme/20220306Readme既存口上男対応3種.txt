eraGVT社会派220302用既存口上オトコ対応３種パッチ

★概要
既存の口上、真面目、ツンデレ、無口をオトコに対応させました。
既存EV男の娘対応で抜けがあったので、２つのファイルを修正しました。
衣装の下着保護、挿入抵抗カスタマイズの数値処理が逆転していたと思われるので修正しました。


★導入方法
以下の環境に上書きしてください。
・eraGVT_社会派触手ニュース版220302


★具体的な変更点（憶えている限りの）
・口上については主に台詞をオトコっぽくし、
　地の文を、オトコでもオンナでも不自然ではないようにしただけです。
　新たに追加した部分はほぼありません。
　対応した性格のキャラクターで汎用オトコ口上を選べば使用できます。
　オトコっぽい口調の女の子、ということでも使えるかと思います。

・既存EV男の娘対応で追加したファイルは次の２種類です。
　ENDING.ERB
　MESSAGE_SUBEVENT.ERB
　ほんのちょっとの修正なので大した影響はないと思います。

・衣装の挿入抵抗カスタマイズの数値処理の修正については、
　衣装固定カスタマイズ.txtにて、「値が低いほど下着保護力が高くなる」とあるので、
　おそらくその辺りが原因で計算ミスが生じたと判断しました。
（修正といっても一箇所、+=を-=に変えただけです）


★やりたいことリスト
・エルデンリングで囚人服を着て駆け回る

・触手拘束具の強制装着の機会を増やす
　撤退時にも強制装着の機会を作る
　撤退成功すると伏兵触手に不意打ちを食らう（防衛力で35%～85%に変化）
　回避判定で失敗すると衣装耐久度が残っていても強制装着
　衣装耐久度が元々減っている場合は上記に加えて時間切れ時と同じ確率で強制装着
　時間切れ時より強制装着されやすくすることで撤退のリスクを高めてみたい

・触手拘束具を外し難くする
　触手の欠片２個と5000$くらい必要にして、しかも確率で失敗するように
　失敗確率は欲望と触手中毒のレベルと、淫乱と触手の虜の有無で変化
　１レベルごとに5%、淫乱と触手の虜で10%ずつ減少くらい？（解除成功率90～20%）
　絶対外したいときはセーブ＆ロードできるからいいよね、くらいの気持ちで……

・長期戦モード（仮）を追加する
　刻印や性的ステータスの成長が５分の１？の速度になる
　代わりに被ダメージと与ダメージが雑に半分になる（各種回復量は変化なし）
　ラスボス触手が無理ゲーになる可能性あり
