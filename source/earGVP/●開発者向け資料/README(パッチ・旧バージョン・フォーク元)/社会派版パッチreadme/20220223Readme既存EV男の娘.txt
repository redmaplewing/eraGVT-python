eraGVT社会派220213用既存イベント男の娘対応パッチ

★概要
既存イベントを男の娘に対応させました。
男の娘は男女平等フィルタの影響を受けません。

元々オトコに対応していなかったイベントも、
女性器が必要なものでなければ出来る限り男の娘に対応させています。

ただし、戦闘系の対応はまだ完全ではありません。
（例えば搾り取るコマンドで男の娘はアナルで搾り取れるようにしたいのですが、
　戦闘系の処理を解読しきれずに手を出せていません……）

少しですが不具合などもついでに修正しています。
念のため、本パッチは元のファイルをバックアップのあと、適用してください。


★導入方法
以下の環境に上書きしてください。
・eraGVT_社会派触手ニュース版220213


★具体的な変更点（憶えている限りの）
・男女フィルタに関係なく男の娘は犯されるように既存イベントを変更
・男の娘含むオトコでも地の文が不自然ではなくなるように分岐を追加
　（三項演算子を多用しているので読みにくくなってしまっているかも……）
・男の娘のＡセックス関係は一部Ｖセックス関係を流用したものを追加
　（その場合はＡ感覚が１以下で処女と似たような扱いをされます）

・ボス触手襲撃の際にターン数がおかしくなっていた不具合を修正
・インナーを着替えたときメッセージが表示されなかった不具合を修正
・その他、目についた誤字脱字と思われる部分は修正しています

・エルデンリング、おおエルデンリング
・息抜きがてらに意地っ張りor素直口上作成

★やりたいけど難しそうなもの
