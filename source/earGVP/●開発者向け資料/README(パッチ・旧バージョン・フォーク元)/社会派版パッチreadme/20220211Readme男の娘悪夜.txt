eraGVT社会派220121用男の娘対応悪堕ち夜這いイベントパッチ

★概要
まだまだ男の娘用にイベント修正中ですが、
あまりに量が多いので先んじて悪堕ち襲撃と夜這いだけ試しに公開してみます。

意図としては修正方針を試して貰うというのと、
デバッグも兼ねて欲しいという目的があります。
特に夜這いの方は２キャラの性別が影響し合い複雑なので……。

最低限のチェックはしているのでエラー落ちすることは（多分）ないはずです。
悪堕ちと夜這いを選んだのは単一ファイルで地の文も完成されているからです。
素晴らしい地の文と理解しやすい綺麗な構文を書いてくれた先人に感謝……！

本パッチはeraはおろかプログラミング素人が作成したものです。
品質には注意していますがどこかおかしいところがないとも言い切れません。
というか多分あるので自己責任でバックアップはしておいてください。

★導入方法
フォルダごと以下の環境の「強制発生イベント」フォルダに上書きしてください。
・eraGVT_社会派触手ニュース版220121
＋eraGVT社会派220121用バグ&膨乳数値修正パッチ
＋eraGVT汎用豹変口上パッチ
＋eraGVT衣装設定画面修正パッチ
＋（上気のパッチを入れたあとで）eraGVT男の娘パッチ


【具体的な変更点（憶えている限りの）】
男の娘は男女平等フィルターの影響を受けません。
ONだろうとOFFだろうと膣がなくペニスがあるという点以外は女扱いを受けます。
三人称でも基本的に意図的に女の子扱いしています。

基本的に既存の地の文をコピー改変させて頂いたもので追加はほぼしていません。
（男の娘のＡ系夜這いをＶ系夜這いの改変にしたりはしてますが）
ただ、Ｂ夜這いだけは相手の欲望が高い場合のパターンが物足りなかったので、
僭越ながら自分が男の娘で相手の欲望が高い場合だけまるまる追加しました。

また、今後の方針的にも基本的には元々オトコ対応してないものは、
男の娘に対応はさせても男の娘ではないオトコに対応はさせないつもりです。
が、悪堕ち襲撃だけは男の娘ではないオトコにも対応させてみました。
もちろん、男の娘ではないオトコの場合は男女平等化フィルターの影響を受けます。

なにかありましたらスレで教えて頂ければ修正します。
今回修正された悪堕ち襲撃や夜這いイベントで、
オトコなのにＶ経験が入った、地の文で膣があること扱いにされている、
など些細なことでも教えて貰えると助かります。
